# LOVE DNA

연애 심리테스트 + 궁합 매칭 웹앱 (MVP). 순수 HTML/CSS/JS로 만들어져 있어서 빌드 과정 없이 그대로 배포할 수 있습니다.

## 폴더 구조

- `index.html` — 랜딩 페이지
- `test.html` — 정보 입력 + 18문항 테스트
- `result.html` — 개인 결과 / 두 사람 궁합 결과 (URL 파라미터로 분기)
- `js/logic.js` — 질문 데이터, 채점, 캐릭터 매칭, 궁합 계산, 링크 인코딩 로직
- `js/radar.js` — 레이더 차트 (외부 라이브러리 없이 순수 SVG)
- `js/test.js`, `js/result.js` — 각 페이지 동작

## 어떻게 작동하나요

1. 사용자가 정보를 입력하고 18문항에 답하면 6가지 능력치(애정표현/질투/독립성/헌신/감정민감도/갈등회피)를 계산합니다.
2. 결과는 서버 없이 **결과 데이터를 압축해서 URL 안에 그대로 담는 방식**으로 공유됩니다 (`result.html?d=...`). 그래서 지금 단계에서는 데이터베이스가 필요 없습니다.
3. 상대방이 그 링크를 열고 `?partner=` 파라미터로 테스트를 이어서 하면, 두 사람의 데이터를 비교해 궁합 점수를 계산합니다 (`result.html?d=내데이터&p=상대데이터`).
4. "캐릭터 카드 저장" 버튼은 브라우저 안에서 Canvas로 이미지를 직접 그려서 저장합니다 (별도 이미지 생성 서버 필요 없음).

## 로컬에서 미리보기

터미널에서 이 폴더로 이동한 뒤:

```
python3 -m http.server 8000
```

브라우저에서 `http://localhost:8000` 접속.

## Vercel로 배포하기

1. 이 폴더를 GitHub 저장소에 올립니다.
2. Vercel 대시보드에서 "Add New Project" → 방금 만든 저장소 선택.
3. Framework Preset은 "Other"로 두고, Build Command/Output Directory는 비워둔 채로 그대로 Deploy를 누르면 됩니다 (정적 파일이라 빌드 과정이 필요 없습니다).
4. 배포가 끝나면 `내프로젝트.vercel.app` 링크가 생깁니다.

## 아직 안 된 부분 (다음 단계)

- **유료 심층 리포트(AI 분석)**: 지금은 "잠금 해제" 버튼이 안내 문구만 뜨는 placeholder입니다. 실제로 Claude API가 두 사람의 데이터를 보고 리포트를 써주게 하려면 서버 코드(Vercel Serverless Function 등)가 한 단계 더 필요합니다. API 키를 브라우저 코드에 직접 넣으면 노출되기 때문에, 반드시 서버를 거쳐야 합니다.
- **결제 연동**: 심층 리포트를 유료로 팔려면 Stripe/포트원 같은 결제 수단을 붙여야 합니다.
- **공유 시 결과별 미리보기 이미지(OG 이미지)**: 지금은 카카오톡/SNS에 링크를 공유하면 앱 기본 이미지가 뜨고, 결과별 맞춤 카드는 "캐릭터 카드 저장" 버튼으로 사용자가 직접 저장해서 공유하는 방식입니다. 사람마다 다른 미리보기 이미지가 자동으로 뜨게 하려면 이것도 서버 기능이 필요합니다.
